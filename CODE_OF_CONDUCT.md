# Code of Conduct

Vi vil have et respektfuldt og inkluderende projektmiljø.

## Forventet adfærd

- Vær respektfuld og konstruktiv i tone og feedback
- Antag gode intentioner, og spørg hvis noget er uklart
- Hold diskussioner faglige og relevante for projektet

## Uacceptabel adfærd

- Chikane, diskrimination eller nedladende sprog
- Personlige angreb eller vedvarende forstyrrelse af dialog

## Rapportering

Hvis du oplever uacceptabel adfærd, så opret et issue (hvis passende) eller kontakt maintainer via den kanal der er angivet i `SECURITY.md`.
